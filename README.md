# Narthecium
https://github.com/danielqose/Narthecium-NASA/blob/main/narthecium-demo.mp4

Personal-baseline health instrument for a deep-space crew. Team Apothecaries.

It is a simulated 180-day mission. It monitors and explains. It does not diagnose.

```bash
npm install
npm run verify
npm run dev
```

Open the URL Vite prints. The production build is `npm run build` and `npm run preview`.

Story marks on the instrument:

- Day 40, solar particle event
- Day 96, crewmates notice Voss before the curve crosses
- Day 102, sleep drift starts; by day 105 the sentence is “falling for 9 days”
- Day 121, cabin CO₂

The Briefing section is the 7-slide deck. Submission copy is in `SUBMISSION.md`.
